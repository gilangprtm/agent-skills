# Adobe Stock Contributor

Skill independen untuk **quality control, pemeriksaan persyaratan, metadata SEO, dan persiapan ekspor** aset ke Adobe Stock.

Bisa digunakan setelah skill pembuat ilustrasi seperti `vintage-illustration-card`, atau langsung untuk foto, tekstur, dan aset grafis.

## Cara memanggil
- "Siapkan gambar ini untuk Adobe Stock"
- "Audit apakah ilustrasi ini layak upload Adobe Stock"
- "Buat judul dan 49 keyword Adobe Stock untuk gambar ini"
- "Export gambar ini ke JPEG sRGB untuk Adobe Stock"

## Hasil
Laporan status **READY FOR SUBMISSION / NEEDS REVISION / UNVERIFIED / NOT SUITABLE**, data teknis aktual, temuan kualitas dan hak penggunaan, judul SEO bahasa Inggris, deskripsi opsional, keyword berurutan, filename, serta file hasil ekspor **jika benar-benar dibuat**.

Skill ini tidak menjamin persetujuan Adobe, tidak mengunggah otomatis, dan tidak mengarang hasil pemeriksaan. Persyaratan yang dapat berubah harus diverifikasi melalui dokumentasi resmi Adobe.
